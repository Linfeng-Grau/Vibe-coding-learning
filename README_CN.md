# 南京工业大学 门户网站（纯静态演示）

一个**零依赖、零构建**的学校门户网站演示项目。全部由原生 HTML + CSS + JavaScript 编写，
数据保存在浏览器的 `localStorage` 中，双击 `index.html` 即可运行，无需安装任何环境。

> ⚠️ **声明**：本项目仅为学习用途的静态演示，**不是南京工业大学的官方站点!!!**。
> 校内信息（学校简介、数据、领导名单、院系设置等）整理自学校官网公开资料，
> 新闻正文为演示用示例文本。页面内容可能存在滞后或偏差，请以 [官网](https://www.njtech.edu.cn) 信息为准。

---

## 快速开始

### 方式一：直接打开

双击 `index.html`，或右键选择「用浏览器打开」。

### 方式二：本地服务器

由于浏览器对 `file://` 协议的部分限制，用本地服务器打开体验更完整：

- **VS Code**：安装 Live Server 扩展 → 右键 `index.html` → `Open with Live Server`
- **Python**：在 `webpage` 目录执行 `python -m http.server 8080`，然后访问 `http://localhost:8080`
- **Node.js**：在 `webpage` 目录执行 `npx serve .`

两种方式功能完全一致，图片与数据均可正常显示。

## 功能一览

### 公开页面
- **首页** `index.html` — 首屏大图、学校数据概览、办学特色、南工要闻、通知公告、学术活动、快速服务入口
- **学校概况** `about.html` — 学校简介、基本情况、校训校风、历史沿革、现任领导、三校区
- **院系设置** `colleges.html` — 11 个学部折叠展开，列出下属学院
- **新闻公告** `news.html` — 分类筛选（南工要闻 / 通知公告 / 学术活动）+ 关键词搜索 + 分页
- **新闻详情** `news-detail.html?id=N` — 正文、浏览量自增、相关阅读

### 角色页面（需根据演示账号登录）
- **课程表** `courses.html` — 学生看本班课表；教师看自己授课安排；管理员可切换任意班级
- **成绩查询** `grades.html` — 学生看按学期分组的成绩单、加权平均分与 4.0 制绩点；教师看所授课程全班成绩（只读）
- **后台管理** `admin.html`（仅管理员）— 数据概览、新闻增删改查、用户增删改查、重置演示数据

### 通用能力
- **中英双语**：导航栏右上角 `中文 / EN` 切换，无需刷新；新闻、课程、学院等业务数据均为双语字段
- **响应式布局**：桌面端、平板、手机自适应，窄屏下导航折叠为汉堡菜单
- **无障碍**：跳转到主内容链接、`aria-*` 标注、键盘可操作的模态框（Esc 关闭）、焦点管理

## 数据说明

### 存储位置

所有数据保存在浏览器 `localStorage` 中，键名以 `njtech_` 开头：

| 键名 | 内容 |
| --- | --- |
| `njtech_users` | 用户账号（含角色、学院、班级、学号等） |
| `njtech_news` | 新闻公告（中英双语标题、摘要、正文） |
| `njtech_courses` | 课程表数据 |
| `njtech_grades` | 成绩数据 |
| `njtech_session` | 当前登录会话 |
| `njtech_lang` | 语言偏好（`zh` / `en`） |
| `njtech_seed_version` | 种子数据版本号 |

数据仅在**当前浏览器**中有效，不同浏览器或设备之间不共享。

### 重置数据

- **后台方式**：以管理员登录 → 后台管理 → 左侧「重置演示数据」
- **手动方式**：浏览器开发者工具 → `Application` → `Local Storage` → 删除 `njtech_` 开头的键，然后刷新页面

### 修改种子数据

若需修正或扩充初始数据，编辑 `js/store.js` 中的 `seedUsers()`、`seedNews()`、
`seedCourses()`、`seedGrades()` 以及顶部的 `SCHOOL` 常量，然后把 `SEED_VERSION`
改成新值（例如 `1.0.1`）。页面下次加载时会自动重建数据。

### 学校信息字段

`js/store.js` 顶部的 `SCHOOL` 对象集中存放了学校简介、基本情况、办学特色、数据统计、
校区、现任领导、历史沿革、学部学院、快速链接等中英双语内容，需要更新校情时改这一处即可。

## 权限设计

| 角色 | 可访问页面 |
| --- | --- |
| 游客 | 首页、学校概况、院系设置、新闻列表、新闻详情、登录页 |
| 学生 student | 上述页面 + 课程表（本班）、成绩查询（本人） |
| 教师 teacher | 上述页面 + 课程表（自己授课）、成绩查询（所授课程，只读） |
| 管理员 admin | 上述页面 + 后台管理（新闻与用户 CRUD），可查看任意班级课表与全部成绩 |

守卫逻辑位于 `js/auth.js`。页面在脚本开头调用 `Auth.guard([...])`：
- 未登录访问受限页 → 跳转 `login.html?redirect=原地址`，并在登录页给出提示
- 已登录但角色不符 → 提示无权访问并跳回首页

## 已知限制

1. **纯前端方案**：没有后端服务，数据校验、权限控制全部在浏览器端完成，可被绕过，不具备任何安全性
2. **密码明文**：`njtech_users` 中密码为明文存储，仅为演示方便
3. **数据不共享**：换浏览器、换设备或清理浏览器数据后，数据会回到初始状态
4. **教学示例数据**：课程表、成绩、班级均属虚构示例，依据专业培养方案结构编排，非真实教学安排
5. **绩点换算**：采用常见的百分制分段换算（90 分及以上为 4.0），各校算法不同，此处仅作演示口径
6. **院系清单**：依据学校官网「院系设置」公开内容整理，可能与最新调整存在差异
7. **无测试与构建**：项目未包含单元测试与打包流程，代码以可直接阅读、调试为目标

## 技术要点

- **数据层**：`js/store.js` 是唯一的数据出入口，封装了 localStorage 读写、种子初始化、
  各实体 CRUD 与查询统计；若 localStorage 不可用（如隐私模式），会自动降级为内存存储并在页面上提示
- **国际化**：HTML 中用 `data-i18n` / `data-i18n-placeholder` / `data-i18n-html` 等属性标注文案，
  切换语言时统一重渲染；业务数据通过 `I18N.pick(obj, 'title')` 按当前语言取 `titleZh` / `titleEn`
- **共享 UI**：`js/ui.js` 动态注入页头与页脚，避免 9 个页面重复维护；同时提供模态框、Toast、分页等组件
- **零依赖**：不引入任何第三方库、字体或 CDN 资源，完全离线可用（页脚的外部链接需联网访问）
